2. Теоретические сведения
2.1. Массивы в PHP
Массив в PHP - это структура данных, предназначенная для хранения нескольких значений в одной переменной. Каждый элемент массива имеет ключ, по которому можно получить доступ к его значению.
В PHP используются три основных вида массивов:
•	Индексированные массивы - элементы имеют числовые индексы.
•	Ассоциативные массивы - элементы имеют именованные ключи.
•	Многомерные массивы - массивы, содержащие другие массивы.
Пример:
$numbers = [10, 20, 30];

$student = [
    "name" => "Nichita",
    "group" => "I2502"
];
2.2. Функции в PHP
Функция - это именованный блок кода, предназначенный для выполнения определённой задачи. Функции позволяют повторно использовать код, передавать параметры и возвращать результат с помощью оператора return.
Пример:
$transactions = [
    [
        "id" => 1,
        "date" => "2026-09-01",
        "amount" => 100.00,
        "description" => "Payment for groceries",
        "merchant" => "SuperMart"
    ],
    [
        "id" => 2,
        "date" => "2026-09-05",
        "amount" => 75.50,
        "description" => "Dinner with friends",
        "merchant" => "Local Restaurant"
    ]
];

                Контрольные вопросы 
1.Что такое массивы в PHP?
Массив - это структура данных, представляющая собой упорядоченный набор элементов, к каждому из которых можно обратиться по числовому индексу. 
2. Каким образом можно создать массив в PHP?
Массив можно создать с помощью конструкции array() или короткого синтаксиса [].
Пример индексированного массива:
$numbers = [10, 20, 30];
Пример ассоциативного массива:
$student = [
    "name" => "Ion",
    "group" => "I2502"
];
3. Для чего используется цикл foreach?
Цикл foreach используется для последовательного перебора элементов массива. Он позволяет получить значение каждого элемента и при необходимости его ключ, не управляя индексами вручную.
Пример:
$numbers = [10, 20, 30];

foreach ($numbers as $number) {
    echo $number . "<br>";
}
В результате будут выведены числа 10, 20 и 30, каждое на отдельной строке.
